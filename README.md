# 미아 — 파티형 메타버스 공포 방탈출

일곱 가지 테마: 귀문(서하리 분교 실종사건) · 오필리아호의 마지막 항해 · 인형의 집 · 백야 요양병원 · 반딧불 캠프 · 레드 메사 · 츠바키야

귀여운 3D 아바타로 함께 하는 멀티플레이 한국 괴담 공포 방탈출.

## 실행

```bash
npm install
npm start
```

- 이 컴퓨터: http://localhost:3000
- 같은 와이파이의 친구: 서버 콘솔에 표시되는 `http://192.168.x.x:3000`
  - 단, 브라우저 보안 정책상 **마이크(음성채팅)는 https 또는 localhost 에서만** 동작합니다.
- 바깥 친구와 음성까지 쓰려면 https 터널 사용 (예: Cloudflare Tunnel)
  ```bash
  cloudflared tunnel --url http://localhost:3000
  ```
  표시되는 `https://….trycloudflare.com` 주소를 친구에게 공유하세요.

## 🔗 공유 서버 (친구들과 인터넷으로 함께하기)

### 방법 1 · 내 컴퓨터를 공유 서버로 (가장 간단)
1. Cloudflare 터널 프로그램 설치 (한 번만):
   ```bash
   winget install --id Cloudflare.cloudflared
   ```
2. **`공유서버 시작.bat`** 더블클릭 (또는 `npm run share`)
3. 창에 뜨는 `https://….trycloudflare.com` 주소를 친구에게 보내기 — 게임 안 오른쪽 위 "친구 초대 주소"에도 표시됩니다.
   - https 라서 음성채팅까지 됩니다. 창을 닫으면 서버가 꺼지고, 다시 켜면 주소가 바뀝니다.

### 방법 2 · 24시간 켜져 있는 온라인 서버 (Render 무료)
1. 이 폴더를 GitHub 저장소로 올리기
2. https://render.com → New → Blueprint → 저장소 선택 (`render.yaml` 이 자동 적용)
3. 배포가 끝나면 `https://gwimun-xxxx.onrender.com` 주소로 누구나 접속
   - 무료 플랜은 15분간 접속이 없으면 잠들었다가 첫 접속 때 30초쯤 걸려 깨어납니다.
   - 무료 서버는 디스크가 초기화되므로, 기록을 남기려면 아래 **무료 데이터베이스**를 연결하세요.

### 기록 저장 · 무료 데이터베이스 (Neon)
환경 변수 `DATABASE_URL` 이 있으면 이어하기·랭킹·하트 기록을 Postgres 데이터베이스에 저장하고, 없으면 지금처럼 `data` 폴더에 저장합니다.
1. https://neon.tech 가입 (카드 필요 없음) → 프로젝트 만들기 (지역: Singapore 또는 Tokyo)
2. 대시보드의 **Connect** → 연결 주소(`postgresql://...neon.tech/neondb?sslmode=require`) 복사
3. Render 서비스 → **Environment** → `DATABASE_URL` 에 붙여넣고 저장 (자동으로 다시 배포됨)
4. 서버 로그에 `기록 저장: 무료 데이터베이스` 가 보이면 성공. 표는 처음 실행할 때 자동으로 만들어집니다.
- 내 PC 기록을 옮기려면: PC에서 `DATABASE_URL` 을 같은 주소로 지정하고 한 번 실행하면, DB가 비어 있을 때 `data` 폴더 기록을 그대로 올립니다.
- Supabase 등 다른 무료 Postgres 주소도 그대로 쓸 수 있습니다.
- Docker 를 쓰는 다른 호스팅(Fly.io, Railway 등)은 동봉된 `Dockerfile` 로 배포할 수 있습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `server/index.js` | 접속, 파티(최대 4명), 전체/파티 채팅, 음성 신호 중계, 저장 |
| `server/game.js` | 방탈출 진행 엔진 (퍼즐 판정, 아이템, 협동 장치, 귀신 AI, 힌트, 엔딩) |
| `server/chapters.js` | 스토리 · 7개 챕터 · 퍼즐 데이터 (여기만 고치면 콘텐츠 수정 가능) |
| `server/items.js` | 아이템 · 조합식 |
| `public/js/*.js` | Three.js 3D 클라이언트 (아바타, 소품, 월드, 사운드, 점프스케어, WebRTC 음성) |
| `data/saves.json` | 파티장 닉네임별 도달 챕터 (이어하기) |
