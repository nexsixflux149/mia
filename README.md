# 미아 — 파티형 메타버스 공포 방탈출

열 가지 테마 + 히든 1: 달빛 문방구(입문) · 귀문(서하리 분교 실종사건) · 오필리아호의 마지막 항해 · 인형의 집 · 백야 요양병원 · 반딧불 캠프 · 레드 메사 · 츠바키야 · 삐에로 · 해피니스 랜드 · (히든) 데드 시티

귀여운 3D 아바타로 함께 하는 멀티플레이 한국 괴담 공포 방탈출.

## 실행

```bash
npm install
npm start
```

- 이 컴퓨터: http://localhost:3000
- 같은 와이파이의 친구: 서버 콘솔에 표시되는 `http://192.168.x.x:3000`
  - 단, 브라우저 보안 정책상 **마이크(음성채팅)는 https 또는 localhost 에서만** 동작합니다.
- 바깥 친구와 음성까지 쓰려면 https 터널 사용 (예: Cloudflare Tunnel)
  ```bash
  cloudflared tunnel --url http://localhost:3000
  ```
  표시되는 `https://….trycloudflare.com` 주소를 친구에게 공유하세요.

## 🔗 공유 서버 (친구들과 인터넷으로 함께하기)

### 방법 1 · 내 컴퓨터를 공유 서버로 (가장 간단)
1. Cloudflare 터널 프로그램 설치 (한 번만):
   ```bash
   winget install --id Cloudflare.cloudflared
   ```
2. **`공유서버 시작.bat`** 더블클릭 (또는 `npm run share`)
3. 창에 뜨는 `https://….trycloudflare.com` 주소를 친구에게 보내기 — 게임 안 오른쪽 위 "친구 초대 주소"에도 표시됩니다.
   - https 라서 음성채팅까지 됩니다. 창을 닫으면 서버가 꺼지고, 다시 켜면 주소가 바뀝니다.

### 방법 2 · 24시간 켜져 있는 온라인 서버 (Render 무료)
1. 이 폴더를 GitHub 저장소로 올리기
2. https://render.com → New → Blueprint → 저장소 선택 (`render.yaml` 이 자동 적용)
3. 배포가 끝나면 `https://gwimun-xxxx.onrender.com` 주소로 누구나 접속
   - 무료 플랜은 15분간 접속이 없으면 잠들었다가 첫 접속 때 30초쯤 걸려 깨어납니다.
   - 무료 서버는 디스크가 초기화되므로, 기록을 남기려면 아래 **무료 데이터베이스**를 연결하세요.

### 기록 저장 · 무료 데이터베이스 (Neon)
환경 변수 `DATABASE_URL` 이 있으면 이어하기·랭킹·하트 기록을 Postgres 데이터베이스에 저장하고, 없으면 지금처럼 `data` 폴더에 저장합니다.
1. https://neon.tech 가입 (카드 필요 없음) → 프로젝트 만들기 (지역: Singapore 또는 Tokyo)
2. 대시보드의 **Connect** → 연결 주소(`postgresql://...neon.tech/neondb?sslmode=require`) 복사
3. Render 서비스 → **Environment** → `DATABASE_URL` 에 붙여넣고 저장 (자동으로 다시 배포됨)
4. 서버 로그에 `기록 저장: 무료 데이터베이스` 가 보이면 성공. 표는 처음 실행할 때 자동으로 만들어집니다.
- 내 PC 기록을 옮기려면: PC에서 `DATABASE_URL` 을 같은 주소로 지정하고 한 번 실행하면, DB가 비어 있을 때 `data` 폴더 기록을 그대로 올립니다.
- Supabase 등 다른 무료 Postgres 주소도 그대로 쓸 수 있습니다.
- Docker 를 쓰는 다른 호스팅(Fly.io, Railway 등)은 동봉된 `Dockerfile` 로 배포할 수 있습니다.

## 계정 · 랭킹 · 고객소리함 · 기념 사진

- **고정 계정 (가입·로그인 없음)** — 처음 정한 닉네임이 그 **IP · 기기의 고정 계정**이 됩니다 (`server/accounts.js`).
  - 그 기기는 다음부터 닉네임이 잠겨 있고, 자동으로 같은 계정(레벨·코인·이어하기·도장표)으로 들어옵니다.
  - 계정이 있는 닉네임은 그 계정의 기기, 또는 그 계정이 쓰던 IP에서만 쓸 수 있습니다. (남이 닉네임만 따라 써서 계정을 가져가지 못함)
  - 휴대폰 데이터는 IP가 수시로 바뀌고 같은 와이파이의 친구·가족은 IP가 같으므로, IP 하나에 계정이 여럿일 수 있고 기기에 남긴 열쇠로 IP가 바뀌어도 같은 계정을 찾습니다.
  - IP 원문은 저장하지 않고 되돌릴 수 없는 해시만 저장합니다. 120일 넘게 오지 않고 한 번도 플레이하지 않은 계정은 자동으로 정리됩니다.
- **🏆 랭킹** — 버튼 하나에 주간 · 월간 · 총 랭킹(레벨 = 얻은 경험치 기준)과 테마별 클리어 시간 랭킹이 함께 있습니다. 주간은 월요일 0시, 월간은 1일에 새로 시작합니다 (한국 시간).
- **👑 주간랭킹 1위 · 황금 고양이 세트 (비매품)** — 주(월요일 0시, 한국 시간)가 바뀌면 서버가 **지난주 1위**를 확정합니다 (`server/index.js` 의 `checkWeek`, 기록은 `stats.weekly`).
  - 광장 **분수대 바로 위에 큰 글씨**로 `주간랭킹 1위는 "닉네임"님 입니다` 가 한 주 동안 뜹니다. (아직 확정된 1위가 없는 첫 주에는 이번 주 지금 1위를 띄웁니다)
  - 1위에게 **황금 고양이 모자 · 가면 · 장갑 · 상의 · 하의 · 신발 · 꼬리** 중 아직 없는 것 하나를 랜덤으로 줍니다. 접속해 있지 않았으면 다음에 들어올 때 알림(우편)이 뜹니다.
  - 7종을 모두 모으면 **🪄 황금 고양이 지팡이**(귀신 퇴치 무제한 — 전설의 검처럼 쓰지만 횟수가 줄지 않음)를 받습니다. 운영자는 처음부터 세트와 지팡이를 모두 가지고 있고, 🎁 선물로 직접 줄 수도 있습니다.
  - 가면은 하얀 바탕에 붉은 무늬 · 황금 눈꼬리를 그린 큼직한 고양이 탈(부드러운 재질)이고, 모자는 귀가 크며, 상의에는 붉은 목줄과 고양이 방울이 달려 있습니다.
  - **고양이 세트와 로봇 코스튬은 함께 입지 않습니다.** 고양이 부위를 입으면(보상으로 받아 바로 입혀질 때도) 입고 있던 로봇 코스튬이 저절로 벗겨지고, 반대로 로봇 코스튬을 입으면 고양이 세트가 벗겨집니다. 🎒 내 물건의 「모두 입기 / 모두 벗기」로 한꺼번에 입고 벗을 수 있습니다.
  - 황금 고양이 아이템은 상점에 전시만 되고(설명: `비매품 - 매주 주간랭킹 1위에게 랜덤 지급되는 아이템`) 살 수도, 일반 사용자끼리 선물할 수도 없습니다. 부위마다 따로 입고 벗습니다 (🎒 내 물건).
  - 서버가 그 시각에 꺼져 있었으면 다시 켜졌을 때 지난주 것을 한 번 확정합니다. 기능이 처음 켜진 주는 기록이 온전하지 않아 건너뛰고, 그다음 월요일부터 지급합니다.
- **소지 개수** — 탈것 · 코스튬 · 날개 · 검 · 비매품은 **아이템별 1개만** 가질 수 있습니다 (사기 · 선물 · 지급 모두). 폭죽류만 여러 개(최대 10개)입니다.
- **휴대폰 잠자기에서 돌아왔을 때** — 화면이 다시 보이면 서버에 연결이 살아 있는지 바로 묻고(`alive`), 2.5초 안에 답이 없으면 스스로 다시 접속해 같은 캐릭터로 이어 갑니다. 화면이 켜진 채 연결이 조용히 죽어도 25초쯤 뒤 알아챕니다. (예전에는 그동안 다른 사람들이 잠들기 전 모습으로 멈춰 보였습니다)
- **🎙️ 음성** — 마이크 줄이 끊기면(화면 꺼짐 · 전화 · 다른 앱) 다시 열고, 이어지지 않는 연결은 4초마다 살펴 다시 겁니다. 통신사 데이터망처럼 서로 직접 이어지지 않는 곳에서는 **중계 서버(TURN)** 가 있어야 들립니다 — 서버 환경변수 `TURN_URLS`(쉼표로 여러 개) · `TURN_USER` · `TURN_PASS` 를 넣으면 자동으로 씁니다 (없으면 STUN 만 사용).
- **📮 고객소리함** — 광장 분수대 옆 빨간 우편함(또는 ⚙ 설정)에서 버그·건의사항을 보냅니다. 운영자는 🛡️ 운영 → 「고객소리함 보기」에서 확인합니다.
- **📸 클리어 기념 사진 · 🎫 도장표** — 테마를 깨면 그 테마의 귀신들과 함께 찍은 사진을 받습니다. 테두리 6종, 저장(휴대폰·PC), 공유 가능. 도장표는 ⚙ 설정 · 🎒 내 물건에서도 볼 수 있습니다.
- **전송량** — 위치 방송은 1초에 10번, 바뀐 사람만 보냅니다 (아무도 움직이지 않으면 보내지 않음). js·css 는 압축해서 보냅니다.
- 화면과 서버가 주고받는 방식을 바꿀 때는 `server/index.js` 와 `public/js/main.js` 의 `PROTO` 숫자를 함께 올리면, 예전 화면을 열어 둔 사람은 자동으로 새로고침됩니다.

## 그래픽 강화 · 글꼴

- **🎨 그래픽 강화** (⚙ 설정 → 「그래픽 강화」, 기본 켜짐) — 벽 · 바닥 · 나무 · 금속에 돌 · 나무결 같은 **결(요철 · 거칠기)** 을 더하고, 소나무에는 가지 · 솔잎을, 풀 · 집(창틀 · 기와 · 벽돌 · 홈통)에는 더 자세한 모양을, 캐릭터에는 깃 · 박음질 · 소매단을 더합니다 (`public/js/graphics-upgrade.js` · `visual-upgrade.js`).
  - **공포 분위기는 예전 그대로**입니다. 조명 · 노출 · 안개 · 해상도 · 화면 효과(흔들림 · 비네트 · 그레인) · 귀신 · 손전등은 건드리지 않고, 새 무늬는 원래 재질의 **평균 색 · 밝기에 맞춰** 입힙니다 (그림의 평균을 재서 나눠 줍니다). 원래의 어둡고 빽빽한 나무 덩어리도 그대로 두고 그 위에 덧입힙니다. 귀신 얼굴 · 몸은 바꾸지 않습니다.
  - 물건의 위치 · 충돌 · 퍼즐 · 움직임은 그대로이고, 재질과 모양만 바뀝니다. 챕터를 나갈 때 바꿔 둔 재질과 만든 모양은 모두 원래대로 돌리고 지웁니다 (기억 장치가 새지 않음).
  - **끄는 법**: ⚙ 설정의 「그래픽 강화」 · 주소 끝에 `?gfx=0` (이번 접속만; `?gfx=1` 은 이번 접속만 켬). 느린 기기에서 8초 동안 평균 22프레임 아래가 이어지면 **자동으로 꺼지고** 설정에 그렇게 표시합니다. 기능 자체를 빼려면 이 기능을 넣은 커밋을 `git revert` 하면 됩니다.
- **글꼴** — 구글 글꼴 일곱 가지를 **게임에 쓰는 글자만 남긴 woff2** 로 줄여 `public/fonts/` 에 담았습니다 (원본 3.2MB → 0.9MB, 첫 화면에는 3개 약 0.45MB). 모두 SIL OFL 이며 라이선스 파일이 함께 있습니다. 파일 이름에 내용 해시가 있고 서버가 1년 캐시로 보내므로 한 번 받으면 다시 받지 않고, 첫 화면 글꼴은 미리 받으며, 글꼴을 기다리는 시간은 1.2초를 넘기지 않습니다. 게임 글에 새 한글이 늘었을 때는 `pip install fonttools brotli` 후 `python scripts/build-fonts.py --download` 로 다시 만듭니다 (`public/fonts/README.md`). 안 돌려도 글자가 깨지지는 않고 없는 글자만 기기 기본 글꼴로 보입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `server/index.js` | 접속, 파티(최대 4명), 전체/파티 채팅, 음성 신호 중계, 저장 |
| `server/game.js` | 방탈출 진행 엔진 (퍼즐 판정, 아이템, 협동 장치, 귀신 AI, 힌트, 엔딩) |
| `server/chapters.js` | 스토리 · 7개 챕터 · 퍼즐 데이터 (여기만 고치면 콘텐츠 수정 가능) |
| `server/items.js` | 아이템 · 조합식 |
| `public/js/*.js` | Three.js 3D 클라이언트 (아바타, 소품, 월드, 사운드, 점프스케어, WebRTC 음성) |
| `server/accounts.js` | 고정 계정 (IP · 기기) |
| `server/progress.js` | 레벨 · 코인 · 상점 · 주간/월간 경험치 · 방문 통계 |
| `public/js/photo.js` | 클리어 기념 사진 (3D 촬영 + 테두리 · 도장표) |
| `public/js/graphics-upgrade.js` · `visual-upgrade.js` | 그래픽 강화 (재질 결 · 나무 · 풀 · 집 · 캐릭터 디테일, 끄고 켤 수 있음) |
| `public/fonts/` · `scripts/build-fonts.py` | 줄여 담은 글꼴 · 다시 만드는 스크립트 |
| `data/saves.json` | 파티장 닉네임별 도달 챕터 (이어하기) |
