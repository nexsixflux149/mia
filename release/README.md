# MIA 전체 수정본 — 운영 원본과 나란히 실행

이 패키지는 기존 게임 전체 소스와 별도 그래픽 클라이언트를 포함합니다. 원래 서버의 파티·멀티플레이·아이템·퍼즐·귀신 AI·챕터/엔딩·음성 신호 중계 코드는 그대로 사용합니다. 운영 웹사이트를 덮어쓰거나 배포하지 않았습니다.

## 가장 빠른 실행

1. `mia-full-remaster.zip`을 **기존 게임 폴더와 다른 새 폴더**에 풉니다.
2. Node.js 20 이상(22 LTS 권장)을 설치합니다. 최초 의존성 설치에는 인터넷이 필요합니다.
3. Windows는 `release/수정본실행.bat`을 실행합니다.
4. 브라우저에서 **http://localhost:3200/** 접속합니다.
5. 닉네임으로 입장한 뒤 기존 로비에서 원하는 테마를 고릅니다. 11개 테마/58개 챕터의 콘텐츠·해금 규칙을 그대로 사용합니다.

터미널 공통:

```bash
npm ci
npm run remaster
```

Ctrl+C로 종료하고 같은 명령으로 재실행합니다. 수정본 기록은 `.remaster-data`에만 저장합니다. 기존 `data`/DB/계정 기록은 가져오거나 변경하지 않습니다. 기록을 초기화하려면 서버를 끈 후 **새 수정본 폴더의** `.remaster-data`만 삭제합니다.

같은 PC의 다른 창으로 멀티플레이를 테스트할 수 있습니다. LAN 공유는 PowerShell에서 `$env:REMASTER_HOST="0.0.0.0"` 후 실행하고, 휴대폰/다른 PC에서 서버 PC의 사설 IP와 포트 3200으로 접속합니다. 필요한 방화벽 허용은 사용자 PC에서 설정합니다. 기본은 localhost 전용입니다. 포트가 사용 중이면 REMASTER_PORT를 바꿉니다.

기존 음성채팅의 외부 STUN/HTTPS 또는 localhost 요건은 유지됩니다. 원격 음성은 네트워크/NAT에 따라 다르며, 실제 마이크 송수신은 수동 검증이 필요합니다. 인터넷 없이 게임·로컬 파티·퍼즐·사운드·동봉 폰트는 실행 가능하지만 외부 STUN·원격 연결은 지원을 보장하지 않습니다.

## 모든 챕터를 바로 골라 테스트하기

기본 실행은 원래 해금 규칙을 유지합니다. 전체 챕터를 빠르게 검수하려면 수정본 서버를 끄고 `release/전체챕터테스트.bat`을 실행하세요. 또는 `node release/unlock-test.mjs` 후 `npm run remaster`를 실행합니다.

닉네임 **수정본테스터**로 입장하면 로비의 테마/이어하기에서 모든 챕터를 고를 수 있습니다. 이 도구는 새 수정본의 `.remaster-data/saves.json`에 테스트 해금만 기록합니다. 기존 파일이 있으면 같은 폴더의 backups에 먼저 복사합니다. 운영 `data`, DB, 레벨, 관리자 권한은 건드리지 않습니다. 일반 닉네임의 정상 진행 규칙도 유지합니다. 동시 접속으로 닉네임 뒤에 숫자가 붙으면 다른 창을 종료하고 다시 입장하세요.

## 적용 방식과 되돌리기

- `npm start`: 원본 public 클라이언트를 사용하는 기존 실행 경로입니다.
- `npm run remaster`: `.remaster-client`를 생성하고 수정본을 별도 서버/포트/저장소로 실행합니다. 생산 환경 변수와 `.env`/`.env.local`을 읽지 않습니다.
- `.remaster-client`는 생성 결과이며, 게임 데이터와 서버 권한 판정은 `server/` 원본 코드가 담당합니다.
- 게임 패널의 **원본 보기**는 같은 씬·카메라·진행 상태에서 재질/조명/추가 디테일을 복원합니다. 낮음/보통/높음 옵션은 기존 설정 창과 연결됩니다.
- **운영 원본으로 되돌리는 작업은 필요하지 않습니다. 운영 사이트를 바꾸지 않았기 때문입니다.** 새 수정본 서버만 종료하면 됩니다.

현재 운영 서비스에 반영하려면 별도 승인 후 새 서비스에서 먼저 검증하세요. 원래 호스팅 프로젝트·DB·환경변수·도메인에 이 패키지를 덮어쓰지 마세요. `release/render-preview.yaml`과 `release/Dockerfile`은 새 서비스용 준비 파일이며 배포하지 않았습니다. 원래 render.yaml/Dockerfile은 보존합니다.

Docker가 있는 경우:

```bash
docker build -f release/Dockerfile -t mia-remaster .
docker run --rm -p 127.0.0.1:3200:3200 mia-remaster
```

Docker 실행은 검증 여부를 TEST-RESULTS.md에서 확인하세요.

## 그래픽 적용 범위

전체 테마에서 공통 PBR 표면 디테일, 원래 색감을 유지하는 조명/안개 조정, 후처리/해상도/그림자 옵션, 캐릭터의 의상·입체 코 디테일을 사용합니다. **머리카락은 사용자 피드백대로 원본입니다.** UI·쪽지·문서는 원래 5개 폰트 계열/7개 굵기를 동봉해 사용합니다.

기존 나무는 종류에 맞게 바늘잎 모델을 공유 인스턴스로 표현하고 대나무·메사 등은 원래 형태를 보존합니다. 기존 집에는 창틀·문틀·홈통·일부 테마의 지붕 타일을 추가합니다. 골목 1장의 도로와 주변 콘크리트는 서로 다른 텍스처로 구분합니다. 다른 챕터의 나무/배/병원/다다미/서부 등 **기존 테마 바닥 이미지는 덮어쓰지 않습니다.** 새 공간/충돌/이동 경로는 추가하지 않았습니다.

귀신은 기존 AI/속도/감지/잡기 판정을 유지하면서 여성·아이·소사·이장·무당·기어다니는 귀신·아버지·간호사·선원·좀비의 얼굴 음영/눈빛/옷 표면을 강화합니다. 인형·가면 등 고유 테마 외형은 보존합니다. 그래픽 패널의 **귀신 외형 비교**로 첫 시안을 확인할 수 있습니다. 첫 골목에 없던 추격 귀신을 새로 추가하지는 않습니다.

이 수정본은 공통 렌더링/절차 모델 개선을 전체 게임에 연결한 버전입니다. 모든 챕터의 모든 오브젝트를 새 고해상도 모델로 다시 제작한 AAA 리메이크를 뜻하지 않습니다. 각 챕터 완주·미술 검수·실기기 성능 검증은 추가로 필요합니다.

## 백업 범위

`mia-original-code-backup.zip`은 작업 시작 시 GitHub main의 전체 추적 소스입니다. `live-public-snapshot`은 현재 웹사이트의 공개 클라이언트 23개 파일을 읽어서 보관한 스냅샷입니다. 모두 main 소스와 일치함을 확인했습니다. 자세한 시점/해시는 backup-manifest.json에 있습니다.

**운영 서버 내부 배포 이력, DB, 저장 파일, 환경변수, 인증서/비밀키는 백업하지 않았습니다.** 서버 접근이나 비밀키를 읽지 않고 제작했습니다. 향후 실제 운영 교체를 원하면 호스팅 서비스의 스냅샷/DB 백업을 소유자가 별도로 확보해야 합니다. 이 코드 백업만으로 운영 계정 기록 전체를 복구할 수 있다고 보장하지 않습니다.

## 검증 도구

```bash
npm ci --prefix preview
# preview 폴더에서 npx playwright install chromium (없을 때)
npm run remaster
# 다른 터미널에서:
node release/test.mjs
```

설치된 Chromium을 쓰려면 CHROMIUM_PATH를 지정합니다. 테스트는 58개 챕터의 씬/콜라이더/테마 색/원본 전환, 실제 렌더링과 기존 귀신 애니메이션, 2인 파티·위치/아이템/퍼즐/진행·음성 신호 및 실제 브라우저 클라이언트를 확인합니다. 최종 수행 결과·미검증 항목은 TEST-RESULTS.md에 기록합니다.
